## Replay

Install the hack-day release candidate if needed:

```sh
npm install -g @testmuai/kane-cli@rc
kane-cli login --oauth
```

From the repository root, run one saved test:

```sh
KANE_CLI_USER_AGENT=codex kane-cli testmd run tests/kane/artist-manager-workflow_test.md --agent
```

Or replay both as a suite:

```sh
KANE_CLI_USER_AGENT=codex kane-cli testrun run tests/kane/artist-manager-live-smoke_test.md tests/kane/artist-manager-workflow_test.md < /dev/null
```

The adjacent `output-*` directories contain the recordings required for replay. Keep them beside the corresponding test. Kane can re-author changed or failed replay steps, which can consume credits. Initial sign-in, Chrome readiness and available credits are required. Review any updated recordings before committing them.
